## Longer About Section

FlowDeck is an Excel-native Commodity Trading Intelligence platform for Brent/WTI oil desks. It demonstrates a full synthetic workflow from market data validation through forward curves, physical plus futures exposure, net exposure, hedge simulation, stress P&L, run tracking, and trader-ready Excel report generation.

The current Public Demo V1 flow is:

```text
/demo -> Run Sample Demo -> /runs/[runId] -> Download Excel Report
```

FlowDeck is built as a portfolio-grade applied commodities analytics project with a Python/FastAPI backend, Next.js/React/TypeScript frontend, openpyxl Excel exports, pytest backend tests, and Playwright frontend/E2E coverage. The backend remains the source of truth for financial calculations.

FlowDeck uses synthetic demo data only. It does not include real trade data, licensed market data, API keys, or secrets. It is analytics-only, not trade execution, and hedge outputs require human review.
